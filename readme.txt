# Mobile‑3D‑Night‑HighSchool
🌙 First‑person 3D dusk high‑school scene, runs directly on mobile browser, no app installation required, based on Three.js WebGL.

## Features
- 📱 Mobile touch virtual joystick for character movement
- 👆 Swipe screen to rotate view, first‑person perspective
- 🌑 Dusk‑time dim school corridor and classroom scene
- 📚 Stacked books, exam papers floating in wind simulation
- 📢 On‑screen text hint simulating ambient background voice
- 🧩 Light‑weight implementation, supports low‑end Android devices

## How To Run
1. Clone or download this repository
2. Open `index.html` using system browser, Chrome or Edge browser
> ❗ Do NOT open within WeChat embedded browser, it will result in black‑screen rendering failure.

## Online Preview
Enable GitHub Pages on repository settings to get public online preview link.

## Tech Stack
- Three.js r132
- Pure HTML / Vanilla JavaScript
